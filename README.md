# Shubham Kumar — Personal Developer Portfolio

A clean, modern, and authentic personal portfolio built with semantic HTML5, custom CSS, and vanilla JavaScript. Designed to reflect genuine developer craftsmanship—prioritizing fast load times, accessible design, high-contrast theming, and an interactive presentation of real computer science and algorithmic problem-solving skills.

---

## 🌟 Key Highlights & Philosophy

- **Human-Written & Grounded:** No buzzword-heavy corporate fluff, fake skill percentage bars, or vibe-coded terminal gimmicks.
- **Developer-Centric Aesthetics:** Understated, high-contrast color palette with [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) for body text and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) for technical tags and code snippets.
- **Zero Heavy Dependencies:** Handcrafted with pure web standards. Zero frameworks, zero bulky libraries, zero build steps—instant load times and 100% lighthouse-ready performance.
- **Responsive & Accessible:** Fluid grid and flexbox layouts that scale seamlessly across smartphones, tablets, laptops, and ultra-wide desktop monitors, adhering to semantic HTML5 and ARIA standards.

## 🚀 Features

### 1. High-Contrast Dark & Light Theming
- **Dark Mode (Default):** Deep slate background (`#0B0F17`) with muted emerald (`#10B981`) and amber accents.
- **Light Mode:** Crisp off-white (`#FAFAFA`) with deep charcoal (`#171717`) typography.
- **Smart Persistence:** Remembers user preference via `localStorage` and automatically syncs with system-level `prefers-color-scheme` settings.

### 2. Interactive "My Journey & Aims" Story Explorer

- **Interactive Stepper:** Click through numbered milestones (`01 Under The Hood`, `02 Algorithms & DS`, `03 Continuous Learner`, etc.) with animated transitions, core takeaways, and tags.
- **Quick Topic Jump Pills:** Instant filters to drill straight down into specific themes (*"Under The Hood"*, *Algorithms & Problem Solving*, *Building Efficient Games*, *Continuous Skill Expansion*).
- **View Toggle:** Seamlessly switch between the interactive milestone stepper and a continuous side-by-side full-text narrative.

  - **Languages:** C++ (Daily driver for CP & game logic), Python (Exploration / ML), JavaScript (ES6+), HTML5 & CSS3.

## 🛠️ Local Development & Quick Start

Because this project uses vanilla web standards, it requires no build tool, package manager, or compilation step.

### Option 1: Open Directly in Browser
Simply double-click `index.html` or open it with your preferred browser.

### Option 2: Run with Python HTTP Server
```bash
# From the project directory:
python3 -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: VS Code Live Server
1. Install the **Live Server** extension in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.

## 🚢 Deployment

This site can be deployed to any static hosting provider within seconds:

### GitHub Pages
1. Push this repository to GitHub.
2. Navigate to **Settings > Pages**.
3. Under **Build and deployment**, select **Source:** `Deploy from a branch` and choose `main` / `/ (root)`.
4. Click **Save**.

### Vercel / Netlify / Cloudflare Pages
- Connect the GitHub repository directly to Vercel or Netlify.
- Since there is no build step needed, leave **Build Command** blank and set the **Output Directory** to `.` (root).
