Graph Theory O((V + E) log V)

Dijkstra's Shortest Path

Calculates the single-source shortest path in weighted graphs with non-negative edge weights using a min-priority queue.

View details & C++ implementation
Time Complexity: O((V + E)*log V)
Space Complexity: O(V + E)

How It Works:

Dijkstra maintains a tentative distance table initialized to infinity, with the start node set to 0. A min-heap (priority queue in C++) greedily extracts the unvisited vertex with the smallest provisional distance, then relaxes each of its outgoing edges. Because edges are non-negative, once a node is popped from the heap, its minimal distance is guaranteed optimal.

Game Dev & Practical Applications:

  • Navigation & Pathfinding: Core foundation for road GPS networks and AI navigation meshes (NavMeshes) on weighted terrain.
  • Network Routing: Open Shortest Path First (OSPF) routing protocol in modern internet architectures.
C++20 (STL priority_queue) 
#include <vector>
#include <queue>
using namespace std;

const long long INF = 1e18;

// Adjacency list: adj[u] = { {v, weight}, ... }
vector<long long> dijkstra(int n, int src, const vector<vector<pair<int, long long>>>& adj) {
    vector<long long> dist(n + 1, INF);
    // min-heap storing {distance, vertex}
    priority_queue<pair<long long, int>, 
                   vector<pair<long long, int>>, 
                   greater<>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (d > dist[u]) continue; // Skip stale heap entries

        for (const auto& [v, weight] : adj[u]) {
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
Dynamic Programming O(N · W) / O(N log N)

DP: Knapsack & LIS Optimization

Solving multi-stage decision problems by decomposing them into overlapping subproblems with optimal substructure.

View details & C++ implementation
0/1 Knapsack Space-Optimized: Time: O(N*W) | Space: O(W)
Longest Increasing Subsequence: Time: O(N*log N) | Space: O(N)

How It Works:

Rather than recalculating combinatorial options recursively, Dynamic Programming records subproblem results. In the 0/1 Knapsack problem, running the capacity loop in reverse allows a single 1D array to suffice without overwriting states from the previous item. In LIS, using patience sorting with std::lower_bound compresses the quadratic recurrence into O(N \log N).

Game Dev & Practical Applications:

  • Inventory & Resource Management: Maximum damage/stat loadout optimization under strict weight or stamina constraints.
  • Game AI Decision Trees: Evaluating sequences of player moves with deterministic outcome values.
C++20 (1D Rolling DP & LIS) 
#include <vector>
#include <algorithm>
using namespace std;

// 0/1 Knapsack with 1D Memory Optimization O(W) space
int knapsack(int W, const vector<int>& wt, const vector<int>& val) {
    vector<int> dp(W + 1, 0);
    for (size_t i = 0; i < wt.size(); ++i) {
        // Iterate backward so each item is selected at most once
        for (int w = W; w >= wt[i]; --w) {
            dp[w] = max(dp[w], dp[w - wt[i]] + val[i]);
        }
    }
    return dp[W];
}

// O(N log N) Longest Increasing Subsequence
int lis(const vector<int>& nums) {
    vector<int> tails;
    for (int x : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return tails.size();
}
Data Structures Query & Update O(log N)

Segment Tree (Point & Range)

A versatile binary tree supporting logarithmic dynamic point updates and range associative queries (Sum, Min, Max, GCD).

View details & C++ implementation
Build Time: O(N)
Point Update & Range Query: O(log N)
Space Complexity: O(4N)

How It Works:

A Segment Tree breaks down an array of size N into hierarchical intervals. The root represents the entire range [0, N-1], and children recursively bisect intervals. When querying any arbitrary subsegment [L, R], the search touches at most O(log N) canonical nodes whose union covers the exact query range.

Game Dev & Practical Applications:

  • Dynamic 1D/2D Collision & Range Queries: Finding the maximum entity altitude or bounding box intersection in changing terrain.
  • Competitive Programming: A staple structure for heavy-light decomposition, range inversion counts, and dynamic metrics.
C++20 (Clean Class Implementation) 
#include <vector>
using namespace std;

class SegmentTree {
    int n;
    vector<long long> tree;

    void build(const vector<long long>& arr, int node, int l, int r) {
        if (l == r) { tree[node] = arr[l]; return; }
        int mid = l + (r - l) / 2;
        build(arr, 2 * node, l, mid);
        build(arr, 2 * node + 1, mid + 1, r);
        tree[node] = tree[2 * node] + tree[2 * node + 1];
    }

public:
    SegmentTree(const vector<long long>& arr) {
        n = arr.size();
        tree.assign(4 * n, 0);
        build(arr, 1, 0, n - 1);
    }

    void update(int node, int l, int r, int idx, long long val) {
        if (l == r) { tree[node] = val; return; }
        int mid = l + (r - l) / 2;
        if (idx <= mid) update(2 * node, l, mid, idx, val);
        else update(2 * node + 1, mid + 1, r, idx, val);
        tree[node] = tree[2 * node] + tree[2 * node + 1];
    }

    long long query(int node, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tree[node];
        if (r < ql || l > qr) return 0;
        int mid = l + (r - l) / 2;
        return query(2 * node, l, mid, ql, qr) + 
               query(2 * node + 1, mid + 1, r, ql, qr);
    }
};
Graph & Grid O(V + E)

BFS / DFS Grid & State Space Search

Fundamental graph traversal techniques for unweighted shortest paths, flood fills, reachability, and topological ordering.

View details & C++ implementation
Time Complexity: O(V + E)
Space Complexity: O(V)

How It Works:

Breadth-First Search (BFS) explores all neighbors level-by-level using a FIFO queue, guaranteeing the minimum step path in unweighted graphs or uniform grids. Depth-First Search (DFS) dives deeply along each branch using the call stack or an explicit LIFO stack, making it ideal for cycle detection, component labeling, and backtracking game state trees.

Game Dev & Practical Applications:

  • Tile-Map Mechanics: Fog-of-war revelation, water/fire propagation, flood-fill terrain tools, and maze generation.
  • Turn-Based Games: Calculating valid unit movement radii on hex or square grids.
C++20 (Multi-directional 2D Grid BFS) 
#include <vector>
#include <queue>
using namespace std;

const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = {0, 0, -1, 1};

// Shortest step distance in an R x C grid (0 = open, 1 = obstacle)
int gridBFS(const vector<vector<int>>& grid, pair<int,int> start, pair<int,int> target) {
    int R = grid.size(), C = grid[0].size();
    vector<vector<int>> dist(R, vector<int>(C, -1));
    queue<pair<int, int>> q;

    q.push(start);
    dist[start.first][start.second] = 0;

    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();

        if (r == target.first && c == target.second) return dist[r][c];

        for (int i = 0; i < 4; ++i) {
            int nr = r + dx[i], nc = c + dy[i];
            if (nr >= 0 && nr < R && nc >= 0 && nc < C) {
                if (!grid[nr][nc] && dist[nr][nc] == -1) {
                    dist[nr][nc] = dist[r][c] + 1;
                    q.push({nr, nc});
                }
            }
        }
    }
    return -1; // Target unreachable
}
Search Paradigm O(log(Range) · check())

Binary Search on Answer

Transforming complex optimization problems into monotonic decision checks (P(x) -> P(x+1)).

View details & C++ implementation
Time Complexity: O(log(Range) · check())
Space Complexity: O(1)

How It Works:

Whenever a problem asks for the minimum capacity, maximum throughput, or optimal threshold, we test whether a predicate function check(val) is monotonic (e.g. if answer x is feasible, every y \ge x is also feasible). Instead of searching blindly, we halve the search boundary at each step in approx 60 iterations even for numbers up to 10^{18}.

Game Dev & Practical Applications:

  • LOD (Level of Detail) & Frustum Culling: Finding the exact distance threshold to maintain a stable 60 FPS frame rate under varying particle loads.
  • Competitive Programming: Ubiquitous in greedy splitting, schedule allocations, and capacity bottlenecks.
C++20 (Monotonic Predicate Pattern) 
#include <vector>
#include <numeric>
using namespace std;

// Predicate: Can we achieve the goal with threshold `mid`?
bool check(long long mid, const vector<int>& items, int maxGroups) {
    int groups = 1;
    long long currentSum = 0;
    for (int val : items) {
        if (val > mid) return false;
        if (currentSum + val > mid) {
            groups++;
            currentSum = val;
        } else {
            currentSum += val;
        }
    }
    return groups <= maxGroups;
}

long long binarySearchAnswer(const vector<int>& items, int k) {
    long long low = 1, high = 1e15, ans = high;
    while (low <= high) {
        long long mid = low + (high - low) / 2;
        if (check(mid, items, k)) {
            ans = mid;
            high = mid - 1; // Try to find a tighter/smaller valid threshold
        } else {
            low = mid + 1;
        }
    }
    return ans;
}
String Algorithms O(N + M) Linear Time

KMP (Knuth-Morris-Pratt) Matching

Linear time exact string matching that avoids redundant backtracking using a precomputed longest prefix-suffix (pi) array.

View details & C++ implementation
Time Complexity: O(N + M)
Space Complexity: O(M)

How It Works:

Naive string matching takes O(N*M) because every mismatch rewinds the text pointer. KMP eliminates rewind by computing an LPS (pi) table for the pattern in O(M). When a mismatch occurs after matching j characters, the LPS array reveals the longest proper prefix that matches a suffix, allowing the search to shift seamlessly without re-examining previously matched characters in the text.

Game Dev & Practical Applications:

  • Command Parsing & Cheat Codes: Real-time keystroke buffer matching for secret key sequences and console triggers.
  • Bioinformatics & Text Processing: Rapid DNA sequence motif analysis and file search engines.
C++20 (LPS Failure Table & Search) 
#include <vector>
#include <string>
using namespace std;

// Build Longest Proper Prefix which is also Suffix table
vector<int> buildLPS(const string& pat) {
    int m = pat.size();
    vector<int> lps(m, 0);
    int len = 0, i = 1;

    while (i < m) {
        if (pat[i] == pat[len]) {
            lps[i++] = ++len;
        } else if (len != 0) {
            len = lps[len - 1];
        } else {
            lps[i++] = 0;
        }
    }
    return lps;
}

// Returns 0-based start indices of all occurrences
vector<int> kmpSearch(const string& text, const string& pat) {
    vector<int> matches;
    if (pat.empty()) return matches;

    vector<int> lps = buildLPS(pat);
    int i = 0, j = 0, n = text.size(), m = pat.size();

    while (i < n) {
        if (text[i] == pat[j]) { i++; j++; }
        if (j == m) {
            matches.push_back(i - j);
            j = lps[j - 1];
        } else if (i < n && text[i] != pat[j]) {
            if (j != 0) j = lps[j - 1];
            else i++;
        }
    }
    return matches;
}
